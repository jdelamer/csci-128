\section{The Standard Pattern: Processing All Pixels}

Before we create filters, let's understand the fundamental structure for processing every pixel in an image.

\subsection*{Activity 1: Understanding Nested Loops}

Here's the pattern you'll use in almost every filter:

\begin{lstlisting}
from PIL import Image

# Load image
img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

# Process every pixel
for x in range(width):
    for y in range(height):
        # Get current color
        r, g, b = pixels[x, y]

        # Calculate new color (this is where the magic happens!)
        new_r, new_g, new_b = r, g, b  # (no change yet)

        # Set new color
        pixels[x, y] = (new_r, new_g, new_b)

# Save and show
img.save("processed.jpg")
img.show()
\end{lstlisting}

\textbf{Understanding the nested loops:}
\begin{itemize}
    \item The outer loop iterates through columns (x-coordinates)
    \item The inner loop iterates through rows (y-coordinates)
    \item Together they visit every single pixel exactly once
    \item For a 800×600 image, the loops run 480,000 times total!
\end{itemize}

\section{Grayscale Filters}

Grayscale (black and white) images have no color—only brightness information. To create grayscale, we make all three RGB channels equal.

\subsection*{Activity 2: Simple Average Grayscale}

The simplest approach is to average the three color channels:

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        # Calculate average brightness
        gray = (r + g + b) // 3

        # Set all channels to the same value
        pixels[x, y] = (gray, gray, gray)

img.save("grayscale_average.jpg")
img.show()
print("Grayscale conversion complete!")
\end{lstlisting}

\textbf{Why it works:} When R = G = B, the pixel appears as a shade of gray. The value determines how bright the gray is (0 = black, 255 = white).

\textbf{Experiment:} Try this on different images. Notice how colorful images become shades of gray!

\subsection*{Activity 3: Luminance Grayscale (Better Method)}

Human eyes don't perceive all colors equally. We're more sensitive to green and less sensitive to blue. Professional grayscale conversion uses weighted averages:

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        # Luminance formula (matches human perception)
        gray = int(0.299 * r + 0.587 * g + 0.114 * b)

        # Set all channels to the same value
        pixels[x, y] = (gray, gray, gray)

img.save("grayscale_luminance.jpg")
img.show()
print("Luminance grayscale complete!")
\end{lstlisting}

\textbf{The weights:}
\begin{itemize}
    \item Green contributes most: 58.7\%
    \item Red contributes next: 29.9\%
    \item Blue contributes least: 11.4\%
\end{itemize}

\textbf{Compare:} Save both versions (average and luminance) and compare them side by side. Can you see the difference? The luminance version usually looks more natural.

\section{Negative Filter}

A negative image is like a film negative in old-school photography—light becomes dark, dark becomes light, and colors invert.

\subsection*{Activity 4: Creating a Negative}

The formula is simple: subtract each color value from 255.

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        # Invert each color channel
        new_r = 255 - r
        new_g = 255 - g
        new_b = 255 - b

        pixels[x, y] = (new_r, new_g, new_b)

img.save("negative.jpg")
img.show()
print("Negative filter applied!")
\end{lstlisting}

\textbf{Color inversions:}
\begin{itemize}
    \item Black (0, 0, 0) → White (255, 255, 255)
    \item White (255, 255, 255) → Black (0, 0, 0)
    \item Red (255, 0, 0) → Cyan (0, 255, 255)
    \item Green (0, 255, 0) → Magenta (255, 0, 255)
    \item Blue (0, 0, 255) → Yellow (255, 255, 0)
\end{itemize}

\section{Brightness Adjustment}

Making images lighter or darker is a common need in photo editing.

\subsection*{Activity 5: Increasing Brightness}

To make an image brighter, add a value to all color channels:

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

amount = 50  # How much to brighten

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        # Add to each channel (but don't exceed 255)
        new_r = min(r + amount, 255)
        new_g = min(g + amount, 255)
        new_b = min(b + amount, 255)

        pixels[x, y] = (new_r, new_g, new_b)

img.save("brighter.jpg")
img.show()
print(f"Brightness increased by {amount}")
\end{lstlisting}

\textbf{Important:} The \texttt{min()} function ensures we don't exceed 255. This is called \textbf{clamping}.

\textbf{Experiment:} Try different amounts (10, 30, 50, 100). What happens with very large values?

\subsection*{Activity 6: Decreasing Brightness}

To darken an image, subtract a value from all color channels:

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

amount = 50  # How much to darken

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        # Subtract from each channel (but don't go below 0)
        new_r = max(r - amount, 0)
        new_g = max(g - amount, 0)
        new_b = max(b - amount, 0)

        pixels[x, y] = (new_r, new_g, new_b)

img.save("darker.jpg")
img.show()
print(f"Brightness decreased by {amount}")
\end{lstlisting}

\textbf{Important:} The \texttt{max()} function ensures we don't go below 0 (clamping again).

\section{Color Tinting}

Tinting adds a color "cast" to an image, like looking through colored glass. This creates mood and atmosphere.

\subsection*{Activity 7: Simple Warm Tint}

A warm tint makes images feel cozy by reducing blue:

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        # Reduce blue channel by 50%
        new_b = b // 2

        # Keep red and green the same
        pixels[x, y] = (r, g, new_b)

img.save("warm_tint.jpg")
img.show()
print("Warm tint applied!")
\end{lstlisting}

\textbf{Why it works:} Reducing blue makes the image appear warmer (more red/yellow tones).

\subsection*{Activity 8: Cool Blue Tint}

Create a cool, night-time feel by reducing red and green:

\subsection*{Activity 9: Sepia Tone (Vintage Photo Effect)}

Sepia creates the warm, brownish tone of vintage photographs:

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        # Sepia transformation (standard formula)
        new_r = int(0.393 * r + 0.769 * g + 0.189 * b)
        new_g = int(0.349 * r + 0.686 * g + 0.168 * b)
        new_b = int(0.272 * r + 0.534 * g + 0.131 * b)

        # Clamp to valid range
        new_r = min(new_r, 255)
        new_g = min(new_g, 255)
        new_b = min(new_b, 255)

        pixels[x, y] = (new_r, new_g, new_b)

img.save("sepia.jpg")
img.show()
print("Sepia tone applied!")
\end{lstlisting}

\textbf{Notice:} Each new color is calculated from all three original colors. This creates the authentic sepia look!

\subsection*{Activity 10: Threshold Filter (Black and White)}

A threshold filter creates pure black and white images (not grayscale):

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

threshold = 128  # Middle of 0-255 range

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        # Calculate brightness
        brightness = (r + g + b) // 3

        # Apply threshold using if-else
        if brightness > threshold:
            # Bright pixels become white
            pixels[x, y] = (255, 255, 255)
        else:
            # Dark pixels become black
            pixels[x, y] = (0, 0, 0)

img.save("threshold.jpg")
img.show()
print(f"Threshold filter applied (threshold = {threshold})")
\end{lstlisting}

\textbf{How it works:}
\begin{enumerate}
    \item Calculate each pixel's brightness
    \item Compare to threshold value
    \item Pixels above threshold → white
    \item Pixels below threshold → black
\end{enumerate}

\textbf{Experiment:} Try different threshold values (64, 128, 192). How does it change the result?

\subsection*{Activity 11: Selective Brightness Boost}

Make only dark pixels brighter (leave bright pixels alone):

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        brightness = (r + g + b) // 3

        # Only boost dark pixels
        if brightness < 100:
            # Make darker pixels brighter
            new_r = min(r + 50, 255)
            new_g = min(g + 50, 255)
            new_b = min(b + 50, 255)
            pixels[x, y] = (new_r, new_g, new_b)
        # else: leave pixel unchanged (implicitly)

img.save("selective_brighten.jpg")
img.show()
print("Dark pixels brightened!")
\end{lstlisting}

\textbf{This is useful for:} Bringing out details in shadows without overexposing bright areas.

\section{Advanced Filters}

\subsection*{Activity 14: Posterization}

Reduce the number of colors for a poster art effect:

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()
width, height = img.size

levels = 4  # Number of levels per channel
step = 256 // levels

for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]

        # Round each channel to nearest level
        new_r = (r // step) * step
        new_g = (g // step) * step
        new_b = (b // step) * step

        pixels[x, y] = (new_r, new_g, new_b)

img.save("posterized.jpg")
img.show()
print(f"Posterized to {levels} levels per channel")
\end{lstlisting}

\textbf{How it works:} Instead of 256 levels (0-255), we reduce to just a few levels (e.g., 4), creating a simplified color palette.

\textbf{Experiment:} Try different numbers of levels (2, 4, 8, 16).

\section*{Understanding Filter Performance}

\begin{itemize}

    \item Nested loops visit every pixel
    \item Complex calculations (like sepia) take longer
\end{itemize}

\textbf{Tips for faster development:}

    \item Use larger images for final results

\section*{Key Concepts Review}

\subsection*{Nested Loops for Image Processing}
\begin{itemize}
    \item Outer loop: x-coordinates (columns)
    \item Inner loop: y-coordinates (rows)
    \item Visit every pixel exactly once
    \item Standard pattern for all filters
\end{itemize}

\subsection*{Color Transformations}
\begin{itemize}
    \item \textbf{Grayscale:} R = G = B (use average or luminance)
    \item \textbf{Negative:} new = 255 - old
    \item \textbf{Brightness:} add (brighter) or subtract (darker)
    \item \textbf{Tinting:} adjust individual channels
    \item \textbf{Sepia:} mix all channels with specific weights
\end{itemize}

\subsection*{Clamping}
\begin{itemize}
    \item RGB values must stay in 0-255 range
    \item Use \texttt{min(value, 255)} to prevent exceeding 255
    \item Use \texttt{max(value, 0)} to prevent going below 0
    \item Essential for brightness adjustments
\end{itemize}

\subsection*{Conditionals in Filters}
\begin{itemize}
    \item Use \texttt{if} to make pixel-by-pixel decisions
    \item Compare brightness, color channels, or positions
    \item Create threshold effects (black and white)
    \item Apply selective modifications
    \item Detect and mark specific colors or regions
\end{itemize}

\section*{Common Issues and Solutions}

\textbf{Image looks too dark/bright after filter:}
\begin{itemize}
    \item Check clamping (min/max functions)
    \item Verify arithmetic (integer division vs float division)
    \item Try adjusting constants (brightness amounts, thresholds)
\end{itemize}

\textbf{Filter has unexpected colors:}
\begin{itemize}
    \item Verify you're modifying the right channels
    \item Check multiplication factors (should be between 0 and 1 for reduction)
    \item Ensure you're using \texttt{int()} for floating-point calculations
\end{itemize}

\textbf{Program is slow:}
\begin{itemize}
    \item Normal for large images!
    \item Test with smaller images first
    \item Avoid unnecessary calculations inside loops
    \item Be patient—image processing takes time
\end{itemize}

\textbf{Syntax errors with conditionals:}
\begin{itemize}
    \item Check for colon (\texttt{:}) after \texttt{if} and \texttt{else}
    \item Verify indentation (use 4 spaces or 1 tab consistently)
    \item Make sure conditions use comparison operators (\texttt{>}, \texttt{<}, \texttt{==}, etc.)
\end{itemize}
