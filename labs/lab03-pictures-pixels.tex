\section{Understanding RGB Colors}

Every pixel in a digital image has a color made from mixing red, green, and blue light. Each component ranges from 0 (none) to 255 (maximum intensity).

\subsection*{Activity 1: RGB Color Explorer}

Let's explore how RGB values create colors. Create a program that prints out some basic colors:

\begin{lstlisting}

# Mixed colors

\end{lstlisting}

\section{Pixel Patterns and Loops}

Nested loops let us create complex patterns by visiting every pixel.

\subsection*{Activity 7: Gradient Generator}

Create a horizontal gradient from black to red:

\begin{lstlisting}
from PIL import Image

# Create a blank image
width, height = 256, 100
img = Image.new("RGB", (width, height), (0, 0, 0))

# Create gradient
for x in range(width):
    for y in range(height):
        # Red increases as x increases
        red_value = x
        img.putpixel((x, y), (red_value, 0, 0))

img.show()
img.save("red_gradient.png")
\end{lstlisting}

\textbf{Your Turn:} Create gradients for green and blue! Try creating a gradient that goes from one color to another (like blue to yellow).

\subsection*{Activity 8: Checkerboard Pattern}

Create a classic checkerboard pattern:

\begin{lstlisting}
from PIL import Image

# Create image
size = 200
square_size = 25
img = Image.new("RGB", (size, size), (255, 255, 255))

# Draw checkerboard
for x in range(size):
    for y in range(size):
        # Determine which square we're in
        square_x = x // square_size
        square_y = y // square_size

        # Alternate colors
        if (square_x + square_y) % 2 == 0:
            img.putpixel((x, y), (0, 0, 0))  # Black
        else:
            img.putpixel((x, y), (255, 255, 255))  # White

img.show()
img.save("checkerboard.png")
\end{lstlisting}

\textbf{Challenge:} Change the colors! Try red and white, or create a rainbow checkerboard.

\subsection*{Activity 10: Efficient Pixel Processing}

For processing many pixels, use the \texttt{load()} method:

\begin{lstlisting}
from PIL import Image

img = Image.open("sample.jpg")
pixels = img.load()  # Faster pixel access
width, height = img.size

# Example: Make top half brighter
for x in range(width):
    for y in range(height // 2):
        r, g, b = pixels[x, y]
        # Increase brightness (cap at 255)
        new_r = min(r + 50, 255)
        new_g = min(g + 50, 255)
        new_b = min(b + 50, 255)
        pixels[x, y] = (new_r, new_g, new_b)

img.show()
\end{lstlisting}

\section*{Important Concepts Review}

\subsection*{RGB Color Model}
\begin{itemize}
    \item Each color has three components: Red, Green, Blue
    \item Each component ranges from 0 to 255
    \item (0, 0, 0) is black, (255, 255, 255) is white
    \item Equal values create shades of gray
    \item This is additive color mixing (like light, not paint!)
\end{itemize}

\subsection*{Image Coordinates}
\begin{itemize}
    \item Origin (0, 0) is at the top-left corner
    \item x increases going right (width)
    \item y increases going down (height)
    \item Always use (x, y) format: width first, then height
\end{itemize}

\subsection*{Key Pillow Functions}
\begin{itemize}
    \item \texttt{Image.open(filename)}: Load an image from a file
    \item \texttt{Image.new(mode, size, color)}: Create a new blank image
    \item \texttt{img.size}: Get (width, height) tuple
    \item \texttt{img.getpixel((x, y))}: Get color at position
    \item \texttt{img.putpixel((x, y), (r, g, b))}: Set color at position
    \item \texttt{img.show()}: Display the image
    \item \texttt{img.save(filename)}: Save to a file
    \item \texttt{img.load()}: Get pixel access object for efficiency
\end{itemize}

\section*{Tips and Tricks}

\begin{itemize}
    \item Always test with small images first (200×200 or smaller) when developing
    \item Use descriptive variable names: \texttt{red\_value} not \texttt{r}
    \item Remember to save your work! \texttt{putpixel()} modifies in memory only
    \item The image file must be in the same folder as your Python program (or use full path)
    \item Use \texttt{min(value, 255)} and \texttt{max(value, 0)} to keep colors in valid range
    \item Nested loops are your friend for processing all pixels
\end{itemize}
