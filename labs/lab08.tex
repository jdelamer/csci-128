\section{Introduction}
% ------------------------------------------------------------------

Last lab we read CSV files and computed basic statistics like minimum, maximum, and average scores. Today we go further: we ask deeper questions about \emph{groups} within the data, and we create charts to tell the story visually.

Real data analysis is rarely just a single number. Employers, researchers, and decision-makers want to know things like ``Which city has the highest average score?'' or ``How does rainfall differ between cities across the year?'' Answering those questions means organizing data into groups, computing per-group statistics, and presenting the results in a way that is immediately readable --- which is exactly what charts are for.

\task{Grouping Data by Category}

Often we want to split a dataset into sub-groups --- all students from Halifax, all students with grade A, and so on --- and then compute something for each group separately. The standard way to do this in plain Python is with a dictionary whose keys are the group labels and whose values are lists of rows.

\textbf{Create the file} \texttt{grouping.py} in your \texttt{lab08} folder.

\textbf{Step 1 --- Implement \texttt{group\_by}:}

\begin{lstlisting}
import csv

def group_by(data, col_name):
    """
    Group rows by the value of a column.

    Returns a dict mapping each unique value to a list of rows.
    Example: {'Halifax': [row1, row3, ...], 'Truro': [...], ...}

    Parameters
    ----------
    data     : list of dicts (as returned by csv.DictReader)
    col_name : str  -- the column to group on
    """
    # Step 1: Create an empty dictionary to hold the groups
    groups = {}

    # Step 2: Loop through every row in the dataset
    for row in data:

        # Step 3: Get the value of the grouping column for this row
        key = row[col_name]

        # Step 4: If we have not seen this key before, create an empty list
        if key not in groups:
            groups[key] = []

        # Step 5: Append this row to the list for its group
        groups[key].append(row)

    # Step 6: Return the completed dictionary
    return groups
\end{lstlisting}

\textbf{Step 2 --- Load the CSV and test the function:}

\begin{lstlisting}
def load_csv(filename):
    """Load a CSV file and return a list of dicts."""
    with open(filename, newline='') as f:
        return list(csv.DictReader(f))


def main():
    data = load_csv('data/students.csv')

    # --- Group by city ---
    by_city = group_by(data, 'city')
    print("=== Students per city ===")
    for city, rows in by_city.items():
        print(f"  {city}: {len(rows)} student(s)")

    # --- Group by grade ---
    by_grade = group_by(data, 'grade')
    print("\n=== Students per grade ===")
    for grade, rows in sorted(by_grade.items()):
        names = [row['name'] for row in rows]
        print(f"  Grade {grade}: {', '.join(names)}")

    main()

\textbf{Connection to image processing:} Grouping is like sorting pixels by colour --- we are organizing data into buckets so we can work on each bucket separately. In Lab 05 you looped over every pixel; here you loop over every row. The pattern is the same: iterate, categorize, collect.
\end{note}

\task{Frequency Counts}

A \emph{frequency count} tells you how many times each unique value appears in a column. It is one of the most common first steps in exploratory data analysis.

\textbf{Create the file} \texttt{frequency.py}.

\textbf{Step 1 --- Implement \texttt{count\_values}:}

\begin{lstlisting}
import csv

def count_values(data, col_name):
    """
    Count how many times each unique value appears in a column.

    Returns a dict mapping each value to its count.
    Example: {'A': 3, 'B': 3, 'C': 2}

    Parameters
    ----------
    data     : list of dicts
    col_name : str -- the column to count values in
    """
    # Step 1: Create an empty dictionary for the counts
    counts = {}

    # Step 2: Loop through every row
    for row in data:

        # Step 3: Get the value in the column of interest
        value = row[col_name]

        # Step 4: If this value has not been seen yet, initialise its count to 0
        if value not in counts:
            counts[value] = 0

        # Step 5: Increment the count for this value
        counts[value] += 1

    # Step 6: Return the completed counts dictionary
    return counts
\end{lstlisting}

\textbf{Step 2 --- Test and sort the results:}

\begin{lstlisting}
def load_csv(filename):
    with open(filename, newline='') as f:
        return list(csv.DictReader(f))


def main():
    data = load_csv('data/students.csv')

    # --- Count grades ---
    grade_counts = count_values(data, 'grade')
    print("=== Grade counts ===")
    for grade, count in sorted(grade_counts.items()):
        print(f"  Grade {grade}: {count}")

    # --- Count cities, sorted by frequency (most common first) ---
    city_counts = count_values(data, 'city')
    print("\n=== City ranking (most students first) ===")
    sorted_counts = sorted(city_counts.items(),
                           key=lambda x: x[1],
                           reverse=True)
    for value, count in sorted_counts:
        print(f"  {value}: {count}")


if __name__ == '__main__':
    main()
\end{lstlisting}

\begin{hint}
\textbf{What is \texttt{lambda}?} The expression \texttt{lambda x: x[1]} is a mini one-line function with no name. It takes a single argument \texttt{x} --- which here is a \texttt{(key, value)} pair from \texttt{.items()} --- and returns just the second element (\texttt{x[1]}), i.e.\ the count. \texttt{sorted()} uses that value to decide the ordering. You could write a full \texttt{def} instead, but \texttt{lambda} is convenient for short cases like this.
\end{hint}

\task{Grouped Bar Charts --- Comparing Two Things}

Sometimes you want to place two bars side by side for each category so the viewer can compare them at a glance. This is called a \emph{grouped} (or \emph{clustered}) bar chart. \texttt{matplotlib} does not have a built-in grouped-bar mode, but it is straightforward with a little arithmetic on the x-positions.

\textbf{Create the file} \texttt{grouped\_bars.py}.

\begin{lstlisting}
import csv
import matplotlib.pyplot as plt

# --- Load data ---
with open('data/weather.csv', newline='') as f:
    data = list(csv.DictReader(f))

cities = ['Halifax', 'Truro', 'Sydney']

# --- Compute average temperature per city ---
avg_temps = []
for city in cities:
    rows = [row for row in data if row['city'] == city]
    avg  = sum(float(r['temp_c']) for r in rows) / len(rows)
    avg_temps.append(avg)

# --- Compute average rainfall per city, scaled to fit the same axis ---
avg_rain = []
for city in cities:
    rows = [row for row in data if row['city'] == city]
    avg  = sum(float(r['rainfall_mm']) for r in rows) / len(rows)
    avg_rain.append(avg / 10)   # divide by 10 so it shares the y-axis cleanly

# --- Bar positions ---
# x is the centre position for each group (one group per city)
x     = [0, 1, 2]
width = 0.35                              # half the gap between groups

# Shift each series left or right of centre by half the bar width
x_temp = [i - width / 2 for i in x]
x_rain = [i + width / 2 for i in x]

# --- Plot ---
plt.figure(figsize=(9, 5))
plt.bar(x_temp, avg_temps, width=width, color='steelblue',
        edgecolor='black', label='Avg Temp (C)')
plt.bar(x_rain, avg_rain,  width=width, color='coral',
        edgecolor='black', label='Avg Rainfall / 10 (mm)')

plt.xticks(x, cities)   # label each group with the city name
plt.title('Average Temperature and Rainfall by City')
plt.xlabel('City')
plt.ylabel('Value')
plt.legend()
plt.grid(axis='y', alpha=0.3)
plt.tight_layout()
plt.savefig('grouped_bars.png')
plt.show()
\end{lstlisting}

\begin{note}
\textbf{The x-position arithmetic explained:} Each city occupies a ``slot'' at position 0, 1, or 2 on the x-axis. We want two bars per slot sitting side by side. By shifting the first bar \emph{left} by \texttt{width/2} and the second bar \emph{right} by \texttt{width/2}, both bars are centred on the slot with no gap between them. \texttt{plt.xticks(x, cities)} then puts the city name label at each slot centre.
\end{note}

\section{Key Concepts}
% ------------------------------------------------------------------

\begin{itemize}
    \item \textbf{Grouping:} Partitioning a dataset into subsets based on the value of a column, stored as a \texttt{dict} mapping keys to lists of rows.
    \item \textbf{Frequency count:} Counting how many times each unique value appears in a column; the result is a \texttt{dict} mapping values to integer counts.
    \item \textbf{Bar chart:} A chart that uses the height of rectangular bars to compare totals or counts across discrete categories (\texttt{plt.bar}).
    \item \textbf{Line plot:} A chart that connects data points with lines to show change across an ordered sequence such as time (\texttt{plt.plot}).
    \item \textbf{Grouped bar chart:} A bar chart with multiple bars per category, shifted horizontally so they sit side by side for direct comparison.
    \item \textbf{Histogram:} A chart that shows the distribution of a continuous variable by dividing the range into equal-width bins and counting data points in each bin (\texttt{plt.hist}).
    \item \textbf{Pipeline:} A sequence of processing stages --- load, process, visualize, save --- where the output of each stage feeds the next.
\end{itemize}
